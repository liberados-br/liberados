# Código de conduta

Este projeto adota o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo: trate todo mundo com respeito, critique ideias e código, nunca
pessoas, e aceite correção com a mesma boa vontade com que a oferece. Não
há espaço para assédio, ofensa, linguagem ou imagem sexualizada, ataque
pessoal ou político, nem para publicar dado privado de alguém sem permissão.
Isso vale nas issues, nos pull requests e em qualquer espaço do projeto.

## Como relatar

Escreva para **contato@liberados.com.br**. Toda denúncia é lida, respondida
e tratada com sigilo. Quem mantém o projeto pode editar ou apagar
comentários, commits, issues e pull requests que contrariem este código, e
afastar, por um tempo ou de vez, quem o violar, seguindo as diretrizes de
aplicação do Contributor Covenant.
